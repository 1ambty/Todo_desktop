# 主题插件接口(Theme Plugin API)

待办的主题是**零代码插件**:把一个 `.json` 文件放进 `themes/` 目录即可。
不需要改任何程序代码,不需要重启开发环境。

## 快速上手

1. 复制 `themes/mist.json` 改名,比如 `mytheme.json`;
2. 修改里面的颜色值(只写想覆盖的,其余自动回落到默认值);
3. 在应用的 **设置 → 扫描主题文件夹** 点一下(或重启应用);
4. 在设置里点新主题卡片即可换肤。

## 文件格式

```json
{
  "id": "mytheme",
  "name": "我的主题",
  "author": "你的名字",
  "vars": {
    "bg": "#eef2e8",
    "accent": "#7fa07a",
    "ink": "#46523f"
  }
}
```

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| `id` | 建议 | 主题唯一标识;缺省用文件名。与内置主题同名可覆盖内置主题 |
| `name` | 建议 | 显示在主题卡片上的名字 |
| `author` | 否 | 作者署名 |
| `vars` | 否 | 颜色/样式变量,见下表;缺省回落默认值 |
| `radius` | 否 | 卡片圆角(px,0~18),写在 `vars` 里 |

> `id` 与内置 `sage` 相同的文件会**覆盖**内置默认主题。

## vars 变量一览

| 变量 | 默认值 | 用途 |
| --- | --- | --- |
| `bg` | `#eef2e8` | 窗体底色 |
| `bg2` | `#f4f7ee` | 辅助底色(预留) |
| `panel` | `#f9fbf5` | 弹层/输入框底 |
| `card` | `#f7faf1` | 任务卡片底色 |
| `card_hover` | `#eef4e6` | 卡片悬停色 |
| `chip` | `#e7eedd` | 小标签/滑轨底色 |
| `accent_soft` | `#dfe9d5` | 选中态弱强调 |
| `accent` | `#7fa07a` | 勾选框/添加按钮 |
| `accent_deep` | `#5f8161` | 文字按钮/选中文字 |
| `ink` | `#46523f` | 主文字 |
| `ink_soft` | `#6c7a63` | 次级文字 |
| `muted` | `#97a58b` | 弱文字/未选中 |
| `line` | `#dde5d0` | 卡片描边/分隔线 |
| `border` | `#ccd8bd` | 窗体外描边 |
| `due` | `#ab8a5c` | 截止日期/连续天数 |
| `danger` | `#bd8d7d` | 删除/逾期/退出 |
| `ok` | `#7fae8a` | 成功色(预留) |
| `scrollbar` | `#c4d1b4` | 滚动条 |
| `radius` | `12` | 卡片圆角(px) |
| `font` | `Microsoft YaHei UI` | 字体(预留) |
| `title` | `待办` | 标题栏文字(可个性化) |

颜色格式:`#RGB` 或 `#RRGGBB`。

## 皮肤脚本(异形 UI,B 路线)

配色不够用时,主题可以带一个 **Python 皮肤脚本**,直接接管界面绘制。
三种放置方式:

| 文件 | 效果 |
| --- | --- |
| `<id>.json` | 纯配色 |
| `<id>.json` + `<id>.py` | 配色走 JSON,绘制钩子走脚本(推荐) |
| `<id>.py` | 脚本自带头部元数据 `SKIN = {"id": ..., "name": ..., "vars": {...}}` |

脚本里定义的钩子(全部可选,未定义的部分走默认绘制):

```python
def on_apply(app):
    """皮肤生效时调用一次。常用:改窗体形状。"""
    app.set_window_shape(radius=180, w=360, h=400)   # 圆角拉满 ≈ 圆形窗

def draw(app):
    """接管主界面层(异形皮肤的主入口)。

    注意:只替代"主界面"(标题栏/列表/输入区那一层);
    设置/编辑/日历/提示等弹层始终由主程序绘制在最上面,
    所以用户永远能打开设置切回别的主题 —— 皮肤不会被自己困住。
    需要自定义弹窗外观时,单独覆盖 draw_settings / draw_edit_modal 等即可。
    """
    c, V = app.canvas, app.V          # 画布与当前主题色
    W, H = app.W, app.H
    c.delete("all")
    app.layout = {"tb": (0, 0, W, 40)}   # 必须给出可拖动区
    ...                            # 随心画:圆盘/便签/角色边框...

def draw_task(app, t, y, w, mode="", shadow=False):
    """只覆盖任务卡片的画法,其余区域用默认。"""
```

可覆盖的钩子 = `TodoApp` 的绘制方法名:`draw`(整窗)、`draw_titlebar`、
`draw_progress`、`draw_tabs`、`draw_task`、`draw_composer`、`draw_list`、
`draw_popover`、`draw_calendar`、`draw_settings`、`draw_edit_modal`、
`draw_toast`、`draw_scrollbar`…

### 交互怎么接

主程序的事件路由是**按画布标签**驱动的,皮肤画的元素挂上约定标签即可复用全部交互:

| 标签 | 作用 |
| --- | --- |
| `act:tb` | 拖动移动窗口的区域 |
| `act:btn-settings` / `act:btn-hide` / `act:btn-pin` / `act:btn-search` | 设置/收起/置顶/搜索 |
| `task:<id>:check` | 点了打勾/取消(每日任务自动计连续天数) |
| `task:<id>` | 点卡片主体(展开备注/拖拽排序) |
| `tab:today` 等、`chip:*`、`act:add` | 选项卡/底部芯片/添加按钮 |

### 约束与安全

- 皮肤出错(语法/运行时)只会让该主题回退默认绘制,并在设置切换时弹提示;
  主程序绝不崩溃;
- 窗体是透明画布:`#FE01FE` 是抠图魔术色,皮肤绘制请避开;
- 圆角 `radius` 之外,窗体轮廓完全由皮肤自己画(圆形/胶囊/异形都行),
  未绘制区域天然点击穿透;
- 切换主题即热重载皮肤;设置 → 扫描主题文件夹 可重新发现新脚本。

完整示例:**圆形时钟**(`themes/clock.json` + `clock.py`)——圆盘表窗、
进度环、任务速览、点击打勾,数据/托盘/热键全部复用。

## 设计约定

- 所有图标都是矢量绘制并以当前主题色着色,插件只需给颜色;
- 建议保持**低饱和、低对比**的色板,与整体"清新自然"的气质一致;
- 透明圆角窗体使用魔术色 `#FE01FE` 抠图,主题颜色请避开这个值。
